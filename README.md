# Talino

An AI career coach for tech: short daily courses, an AI coach chat for freelancing and AI
engineering, a career tracker, a ready-to-use résumé and portfolio, badges, and a certificate when a
course is done. iOS and Android, built with Expo.

## Run it

```bash
npm install
npm run ios        # development build on the iPhone 18 Pro simulator
npm run android    # development build on the Android emulator or a phone
```

After the first build, `npx expo start` is enough for JavaScript changes.

```bash
npm run check      # lint and typecheck
```
