No code, no version notes, no prices or plan limits.
- **The 20-question final assessment** is the quizzes of the four "Knowledge Assessment" lessons (days 37 to 40): **every learner at every one of the five levels is asked exactly five questions in each part = 20**, all with four choices and an explanation. Each part has 4 shared + a newcomer + an advanced + an intermediate-only question (pool of 28, because the shared lesson check tags only `max: 'beginner'` and `min: 'advanced'`; intermediate learners would otherwise see 4). The correct answer sits in each of A to D five times at every level. Part 1 includes machine-learning and deep-learning questions.
- **Passing score:** the app's own rule, **60% per quiz (3 of 5 for an assessment part)**, retakeable at once (`QUIZ_PASS_RATIO`, not changed: it is global). **Completion** = every lesson's quiz passed (so all four assessment parts) and both projects passed review (`computeCourseProgress`), which earns the certificate. A stricter whole-assessment mark (for example 14 of 20) would need an app change.
- Wiring: `registered.json`, `courses.generated.ts`, `course-index.data.ts`, `syllabus.ts`, `scripts/content/build-catalog-index.mjs`, cover (`neural`/`mint`), world "The Lantern Town" (`world-themes.ts`, `adventure-text.ts`), learning paths (`generative-ai`, `build-and-sell`, `freelance-with-ai`, `professional-skills`, first in each; another course's prerequisites needed it in the last two), a side, late-addition journey milestone "AI fundamentals, for everyone" (Beginner; the road to the certificate is unchanged), What's New item `aiFundamentals`.
- **How it differs from the existing courses:** AI Basics for Tech (`starter`, 8 lessons) is a short tech-career course (assistants, prompting, checking work, safe pasting, tools map, picking a career path) and never teaches machine learning, deep learning, neural networks, bias, copyright, deepfakes, industries or the future of work.
