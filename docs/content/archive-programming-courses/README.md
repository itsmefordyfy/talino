# Archived programming-language and framework courses (2026-11-14)

The owner decided on 2026-11-14 that Talino is not a programming academy: no standalone courses on a specific language,
framework or backend technology (JavaScript, TypeScript, Python, React, Next.js, React Native, Expo, Node.js, Supabase,
Firebase, MongoDB, PostgreSQL, Flutter, HTML/CSS, Tailwind...). These files were written (or half-written when the usage limit
stopped the writers) before that decision. Nothing was ever shipped, so no learner progress depends on them.

They are kept as `.ts.txt` (outside the build, tests and lint) because they hold verified, hands-on material that the AI-first
courses may reuse as **supporting lessons in context** ("the technology is the tool, not the subject"): adapt a lesson, never paste a
whole language course back in. 13 were complete and passing every check; the rest are partial (a dead writer's saved work).

Complete: computational-thinking, programming-fundamentals, javascript, typescript, python, dsa, oop, html-css,
responsive-web-design, tailwind-css, mobile-architecture, first-mobile-app, git-github.
Partial or unfinished: ai-agents, ai-chatbots, expo-router, firebase, flutter-dart, fullstack-web, generative-ai-dev, llm-explained,
mongodb, nextjs, nodejs-express, offline-first, postgresql-sql, react-native, react, rest-api, supabase, vector-embeddings.
